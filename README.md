# Профматтренажёр

Кросс-платформенная веб-платформа для интенсивной подготовки к профильной
математике ЕГЭ. Сочетает три формата:

- **Справочник** — краткая теория с формулами KaTeX по разделам, нужным для
  заданий №№2-5, 10 (теория вероятностей, статистика) и №16
  (экономические задачи).
- **Тренажёр** — карточки в стиле Duolingo: задача → ответ → проверка →
  пошаговый разбор. Подсказки выдаются по требованию в три уровня (намёк,
  план, разбор), за решение без подсказок начисляется максимум XP.
- **Агрегатор задач** — все задачи библиотеки с фильтрами по теме, номеру
  ЕГЭ и сложности. Каждая задача связана с темами справочника.

Контент основан на формулировках открытого банка ФИПИ. Все ответы
проверяются юнит-тестами на соответствие независимо вычисленным эталонам.

## Технологии

- **Next.js 14** (App Router) + **TypeScript**
- **Tailwind CSS** — тёмная SaaS-тема, ориентир — Stepik
- **KaTeX** — рендер математических формул
- **Zustand** + `localStorage` — прогресс пользователя (XP, серия дней,
  статистика по задачам). Сервер не нужен.
- **Vitest** — модульные тесты на корректность ответов и целостность данных.

## Локальный запуск

Требуется Node.js 20.19+ или 22.13+.

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

## Проверки качества

```bash
npm run lint       # next lint (eslint + правила Next)
npm run typecheck  # tsc --noEmit
npm run test       # vitest run — проверка корректности 20+ задач
npm run build      # production-сборка Next.js
```

## Структура

```
app/                 # маршруты (App Router)
  page.tsx           # главная
  handbook/          # справочник
  trainer/           # карточки-тренажёр
  tasks/             # агрегатор и страница задачи
components/          # React-компоненты UI
lib/
  types.ts           # доменные типы (Task, HandbookTopic, ...)
  answer-check.ts    # нормализация и проверка ответов
  progress.ts        # zustand-store: XP, streak, статистика
  tasks/             # контент: probability.ts / statistics.ts / economics.ts
  handbook/          # контент справочника по темам
__tests__/           # vitest-тесты
```

## Добавление новой задачи

1. Найдите подходящий файл в `lib/tasks/` (по теме).
2. Добавьте объект, реализующий `Task`. Идентификатор должен быть уникальным.
3. По возможности добавьте `relatedHandbookTopics` для связи со справочником.
4. Допишите проверку правильности ответа в `__tests__/tasks.test.ts`.
5. Запустите `npm run test` — он не должен падать.

## Что покрывает контент

- Теория вероятностей: классическая, объединение и пересечение событий,
  формула Бернулли, формула полной вероятности, геометрическая вероятность.
- Статистика: среднее арифметическое, медиана, размах, частоты, чтение
  графиков.
- Экономические задачи: вклады со сложным процентом и пополнением,
  дифференцированные платежи (вычисление переплаты), аннуитетные платежи
  (формула $x = \frac{S q^n (q-1)}{q^n - 1}$), оптимизация прибыли.
